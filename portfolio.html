輸入持倉

只會儲存喺你呢部機嘅瀏覽器（唔會上載去網站）。換機或者清除瀏覽器資料會唔見，記得用「匯出」備份。同一隻股分幾次買可以分開幾行，計算時會自動合埋（平均成本）。
代號股數買入價（美元）買入日期備註
每隻股用 1 次 Twelve Data 額度（每分鐘最多 8 次，多過 8 隻會自動等）；一個鐘內重複分析會用返舊數據。
設定 Twelve Data API key
同股票分析器共用同一個 key。key 只會儲存喺你呢部機嘅瀏覽器。冇 key？去 twelvedata.com 免費註冊 → API Keys。
只供學習參考，唔係投資建議。止蝕 −8%／+50% 賣一半／跌穿 200 天線係機械人用緊嘅「規則 B」；長短線評分同股票分析器一樣，係按規則自動計分。 價錢嚟自 Twelve Data，可能有幾分鐘延遲。
